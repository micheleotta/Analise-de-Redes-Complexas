# Análise de Redes Complexas com Grafos

Análise exploratória de uma rede complexa de larga escala de plataformas de streaming de vídeo (Netflix, Amazon Prime Video e Disney+) para extração de informações e relacionamentos com estrutura de grafos e algoritmos adequados.

--- 

Leitura do dataset `netflix_amazon_disney_titles.csv`

Construção com lista de adjacências:

1) Grafo direcionado - conexões ponderadas de acordo com a quantidade de colaborações partindo de cada ator/atriz até o nome de cada diretor

2) Grafo não-direcionado - conexões ponderadas (quantidade de colaborações em diferentes obras) entre todos os atores/atrizes que participaram de um mesmo filme/série


* Identificação e contagem de componentes conexos e fortemente conexos
* Função de Árvore Geradora Mínima de componente de vértice X de entrada
* Cálculo de Centralidade de Grau (Degree Centrality) de um vértice
* Cálculo de Centralidade de Intermediação (Betweenness Centrality) de um vértice
* Cálculo de Centralidade de Proximidade (Closeness Centrality) de um vértice
